# 회계 플레이 — 최종 검증 보고서

## 1. 최종 판단
사용자 수정 요청인 **아케이드 테마가 아닌 단순한 회계 학습 제안**에 부합합니다. 실제 화면은 차분한 크림·녹색 계열, 작은 가게 이미지, 거래 기록과 현금·이익 비교 중심입니다. 첨부 화면에서 주요 수치와 버튼의 겹침·심각한 잘림 등 치명적인 시각적 문제는 관찰되지 않았습니다. 이는 제공된 화면 범위의 판단입니다.

## 2. 실행 검증
| 항목 | 기대 | 실제 결과 |
|---|---|---|
| 데스크톱 기본 흐름 | 클릭·단언·스냅샷 정상 | 89개 액션 통과, 포인터 클릭 확인 |
| 데스크톱 sold40 | 수치 및 전체 흐름 정상 | 별도 95개 액션 통과 |
| 375px iframe 재검증 | 좁은 화면과 키보드 조작 정상 | 네이티브 BUTTON의 Enter 활성화로 95개 액션 통과 |
| 재시작 | 홈으로 복귀 | 시작하기·가게 이미지가 있는 홈 DOM 확인 |
| sold120 | 재고 초과 안내 및 기본값 복구 | “100개뿐이라 120개를 팔 수 없어요” 표시 후 홈 복구 |
| 핵심 검사 | 오류 없음 | ledger.check·arcade.check 통과 |
| 컴파일·배포 빌드 | 성공 | TypeScript·Vite 프로덕션 빌드 통과 |

`arcade.check`는 제공된 검사 식별자이며, 현재 UI가 아케이드 테마라는 뜻은 아닙니다.

## 3. 회계 수치 대조
단위는 별도 표시가 없으면 만 원입니다.

| 장면 | 기대값 | 실제 표시 |
|---|---|---|
| 출자 | 현금 +100, 손익 0 | +100 / 0, 현금 T계정 차변 출자 100 |
| 임차료 지급 직후 | 현금 137 + 상품 10 = 자산 147; 부채 50 + 자본 97 = 147 | 모두 일치, 누적 손익 −3 |
| sold40 최종 | 현금 145, 매출 8, 비용 7, 이익 1 | 모두 일치 |
| sold40 비용·재고 | 원가 4 + 임차료 3; 잔여 60개·원가 6 | 모두 일치, 미판매 상품은 비용에서 제외한다고 설명 |
| 첨부 데스크톱 최종 화면 | 60개 판매 기준 현금 149, 매출 12, 비용 9, 이익 3, 잔여 40개 | 모두 일치 |

데스크톱 첨부 화면과 sold40 화면의 결과 차이는 판매 수량 차이에 따른 것으로, 같은 실행의 불일치가 아닙니다.

## 4. 검증 한계
- iframe 내부로의 브라우저 릴레이 클릭이 실패하여 375px 재검증은 **키보드 Enter**로 수행했습니다. 반응형 배치·키보드 동작 검증이지 실제 휴대폰 터치 검증이 아닙니다. 데스크톱 포인터 클릭은 별도로 확인됐습니다.
- iframe 폭은 375px입니다. 중간 기록의 page 값은 360px, 홈 복귀 기록은 page 375px / width 375px입니다. 모든 단계의 page 값이 375였다고 해석하지 않습니다.
- 소리 ON/OFF 라벨과 제어 전환은 확인했으나, 실제 청음에 의한 음질·음량·재생 경험 평가는 하지 않았습니다.
- 실제 모바일 기기 및 Safari 테스트는 수행하지 않았습니다.

BAZE 모델은 제작 과정에서 정적 코드·에셋 생성에 사용됐습니다. 선택 모델은 코딩·QA `gpt-6-astra`, 이미지 `bytedance/seedream-5-pro`, 효과음 `elevenlabs-sfx3effects`, 음악 `lyria-3-clip-preview`입니다. 브라우저 앱은 API 키 없이 동작하며, 런타임 모델 호출이나 AI 채점 기능을 사용하는 것으로 보고하지 않습니다.
